# Açaí Moví — versão premium para GitHub Pages

Esta versão é uma página estática com HTML/CSS/JS e imagens locais, feita para subir diretamente no GitHub Pages sem Vite.

## Como publicar
1. Extraia o ZIP.
2. Envie `index.html` e a pasta `assets` para a raiz do repositório.
3. No GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Observação
O checkout visual e o WhatsApp estão prontos. A cobrança real de Pix/cartão ainda precisa ser ligada a um gateway com confirmação server-side/webhook antes de produção.
